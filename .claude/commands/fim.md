Fim de tarefa. Faça, nesta ordem:

1. Rode npm run check. Se falhar, corrija antes de seguir.
2. Atualize docs/HISTORICO.md com uma entrada no topo: data, o que foi feito (3 a 6 linhas), arquivos principais e o que ficou pendente.
3. Atualize docs/MAPA.md se criou ou moveu arquivos, tabelas, funções ou rotas.
4. Atualize o README.md das features que mudaram.
5. Marque a tarefa em docs/TAREFAS.md.
6. Se tomou uma decisão técnica relevante, crie docs/decisoes/NNNN-assunto.md.
7. Faça o commit no padrão Conventional Commits, faça o push da main e me mostre a lista de arquivos alterados com o número de linhas de cada um. Avise quando estiver no ar em hora-snowy.vercel.app.
